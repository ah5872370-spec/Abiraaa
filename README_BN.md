# Quotex Signal AI — Android Demo Project

এটি একটি **offline educational simulator**। এটি Quotex-এর সঙ্গে যুক্ত নয় এবং কোনো লাইভ মার্কেট ডেটা, নির্ভুল ট্রেডিং সিগন্যাল, অটো-ট্রেড বা লাভের নিশ্চয়তা দেয় না। BUY/SELL/WAIT ফলাফলগুলো র‍্যান্ডম নমুনা ইনপুট থেকে তৈরি।

## Android Studio দিয়ে APK বানানো
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. `QuotexSignalAI_Demo` ফোল্ডারটি Android Studio-তে Open করুন।
3. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. `Build > Build Bundle(s) / APK(s) > Build APK(s)` নির্বাচন করুন।
5. Build সফল হলে `app/build/outputs/apk/debug/app-debug.apk` ফাইলে APK পাওয়া যাবে।

## গুরুত্বপূর্ণ
- এই প্রজেক্টে কোনো Quotex login বা account password লাগবে না।
- কোনো API key, payment, deposit বা real-money trading নেই।
- এটি কেবল UI ও demo interaction দেখানোর জন্য।
